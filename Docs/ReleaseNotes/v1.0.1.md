# QuinSlate 1.0.1

> _Last updated: 2026-08-09_

Released from `v1.0.0..HEAD` (4 commits, version not yet bumped in the manifest).

## User-facing

- **Minimize and maximize buttons on the panel title bar** (`0ed1fa4`). Joins pin and
  close in the custom title bar, growing the overlay cluster from 92 to 172 DIP.
  Minimize genuinely minimizes to the taskbar via a new `isMinimizingToTaskbar` flag
  that bypasses the existing hide-to-tray interception; every other route into
  minimize (hotkey, tray) still hides to tray as before. Window geometry is now
  persisted only in the restored state, so maximizing or minimizing no longer
  clobbers the saved size and position. Default/minimum panel width and the
  tab-strip footer width were bumped to keep five tabs above their floor at the
  wider cluster size. `TabStripCalculatorTests` and `Docs/Wiki/01-TABVIEW-DRAG-REORDER.md`
  updated to match; see also `Docs/Specs/01-CORE.md`, `05-PANEL-POSITION.md`,
  `09-PIN-WINDOW.md`.
- **GitHub link in the About footer** (`4e23ecc`). A themed SVG octocat next to
  "Report an issue" opens the project repository. Monochrome artwork cannot be
  tinted by the framework, so the new `Components/ThemedImageAsset.cs` swaps between
  a light and dark asset pair (`GitHubMark-light.svg` / `GitHubMark-dark.svg`) on
  theme change.

## Internal

- `6f1c28d` Bumped SkiaSharp, Svg.Skia, Windows SDK BuildTools, Windows App SDK,
  Serilog, and Microsoft.NET.Test.Sdk to their latest versions across all four
  projects. No behavior change.
- `19de52d` README correction (tabs are distinguished by name/emoji, not colour).
  No app code.
